# Android Shell

`gomode/` is the native Android shell. `halo/` owns the Halo BLE SDK and
`evenG2/` the Even Realities G2 BLE SDK; `sdk/gomode`, `sdk/mcp`, and
`sdk/voicegateway` own generated Kotlin clients. Fakes that several test source
sets share live in their owning module's Gradle test fixtures, `src/testFixtures`,
which ktlint and Android lint check like its other sources.

Use minSdk 33, target/compileSdk 36, Java 17, coroutines and StateFlow,
`kotlinx.serialization`, and DataStore for persisted settings. Kotlin lines
are at most 120 characters. The Android modules (`gomode`, `car-dial-fixture`,
`halo`, `evenG2`) compile Kotlin with `-Wextra` and warnings as errors: fix a
warning, or suppress its diagnostic at the narrowest scope with a reason; the
generated SDK clients set neither flag. Keep the generated clients free of
Android dependencies. Robolectric tests resolve their runtime jar through
Gradle's offline resolver; update that version alongside Robolectric or
compileSdk.

Read `gomode/AGENTS.md` before editing the app. Keep product task, document,
and database UI in the hosted frontend. Native code owns WebView bootstrap,
permissions, notifications, voice, settings, and glasses integration: Brilliant Halo and Even
Realities G2, one pair connected at a time.

Run `make android-lint android-test` at the repository root after Android changes.
Also run applicable instrumented tests on an emulator: `make android-e2e` runs all
model-free app, gateway, and independent Telecom tests. Use
`uv run --locked python scripts/android_e2e.py --class <Class[#method]>` for focused
app tests, adding `--module telecom` for the independent fixture APK.
If no emulator is present, run `make android-start-emulator` to provision and start
one. Missing emulator images, AVDs, or connected devices do not justify skipping
instrumented test execution.
Run `make android-push` to install and launch the app on a connected device.
Pick a local model under native **Settings → Voice → Separate stages → Language
model** to download its weights. Keep `/data/local/tmp/llm/` resolution for developer and model acceptance fixtures.
